# خطة إعادة تصميم HotLine

## النتيجة
بناء نموذج ويب تفاعلي عربي RTL يعرض تجربة الواجهة الجديدة لتطبيق HotLine بالكامل، مع الحفاظ على وظائف المنتجات والمخزون والمبيعات والديون.

## التنفيذ
- إنشاء نظام بصري داكن بسيط وهادئ بألوان دلالية للمبيعات والمخزون والديون وخط عربي واضح.
- بناء لوحة رئيسية بسيطة للهاتف تعرض أهم الأرقام وإجراءات المسح والإضافة مباشرة دون ازدحام.
- إضافة تنقل فعلي بين الرئيسية والمخزون والمالية والديون، مع شاشات فرعية لإنشاء QR/Barcode والمسح وتفاصيل المنتج والدين.
- جعل النماذج، النوافذ، محددات الكمية، البيع، إضافة المخزون، الدفع والحذف تفاعلية ببيانات تجريبية محلية.
- ضبط عرض بسيط وواضح للهاتف وسطح المكتب، وإضافة بيانات الصفحة التعريفية المطلوبة.

## تفاصيل تقنية
- التنفيذ داخل مشروع React الحالي كنموذج واجهة؛ لن يتم تحويل المشروع إلى Flutter أو ربط Firebase في هذه المرحلة.
- استخدام رموز التصميم الدلالية فقط في ملف الأنماط، وأيقونات Lucide، وحالة React محلية للتجربة.
- التحقق من سلامة العرض والتفاعلات الأساسية على مقاسي الهاتف وسطح المكتب.
